## 📖 概要とコアバリュー

**AIpolloSync** は個人メディアファイルのリモート共有サービスです。ローカルの Flask + WebRTC メディアサーバーを起動し、アウトバウンド FRP トンネルを確立して公衆インターネットアクセスを実現し、WhatsApp 統合 AI エージェントインターフェースを通じてローカルビデオファイルを公開します。

**コアバリュー**: WhatsApp で Hermes に接続し、いつでもどこでもリモートメディアファイルライブラリにアクセスできます。メディアプレイリストは AIpollo プレイヤーでの再生をサポートします。

---

## ⚙️ 前提条件

* **Hermes**: ローカル環境に Hermes が正常にデプロイされていること。
* **セキュリティソフトの例外設定**: Windows Defender などのセキュリティソフトで `frpc.exe` を信頼（除外設定）に追加してください。

---

## 🚀 インストールと利用手順

1. **インストール**: HermesHub から `AIpolloSync` スキルをダウンロードしてインストールします。
2. **動画フォルダの作成**: 本スキルフォルダ内に `videos` ディレクトリを作成し、リモート再生したい MP4 ファイルを保存します。
3. **WhatsApp の連携設定**: Hermes 上で WhatsApp 連携を設定します。
4. **スキルの起動**: Hermes で本スキルを起動します。
5. **LLM 駆動の対話**: チャンネルで自然に AI と会話します。例：
   - *「動画一覧を見せて」*
   - *「何か映画ある？」*
   - *「猫の動画を再生して」*
6. **ワンタップ再生**: 返信から生成されたリンクをクリックして動画を再生します。

## 🔒 セキュリティとネットワーク開示

### 重要: FRP トンネルはローカルサービスを公衆インターネットに公開します

本スキルは起動時に **FRP（Fast Reverse Proxy）クライアント（`frpc`）** を**自動的に**ダウンロードして実行します。`frpc` バイナリは GitHub Releases から取得され、リモート FRP サーバー（`129.213.174.213:7000`）へのアウトバウンドトンネルを確立し、ローカルメディアサービス（ポート 8000）を `*.yunfrp.net` サブドメイン経由で**公衆インターネット**に公開します。

**これにより攻撃対象領域が大幅に拡大します。** 公開サブドメインを知っている、または発見した第三者は、お使いのマシン上のメディアファイルや Flask サービスにアクセスを試みる可能性があります。

### 1. 自動トンネル動作（ユーザー確認なし）

- **起動時に自動実行**: FRP トンネルは `scripts/media_server_flask.py` の実行時に自動的に開始されます。プロンプト、確認、環境変数による制御はありません。
- **バイナリダウンロード**: 初回実行時に `frpc.exe` が GitHub（`fatedier/frp` releases）から自動的にダウンロードされます。インターネット接続が必要です。
- **ファイアウォール変更不要**: トンネルはアウトバウンドのみで、ファイアウォールのインバウンドポート開放は不要です。

### 2. サプライチェーンリスク: ダウンロードバイナリの実行

- 本スキルは GitHub Releases からネイティブバイナリ（`frpc.exe`）をダウンロードして実行します。GitHub リポジトリ、リリースアーティファクト、またはネットワーク転送（MITM）の侵害により、Python プロセスと同じ権限で**任意のコード実行**が行われる可能性があります。
- **SHA256 チェックサム検証**: コードには zip アーカイブと展開された `frpc.exe` バイナリ（バージョン `0.65.0`）の SHA256 チェックサムがハードコードされています。いずれかのチェックサムが一致しない場合、ダウンロードは拒否されます。これは転送の改ざんや破損したダウンロードを防ぎますが、**上流の GitHub リポジトリやリリースの侵害は防げません**。
- **バージョン固定**: FRP バージョンは `0.65.0` に固定されています。アップグレードにはコード変更と SHA256 再検証が必要です。これにより、侵害された可能性のある新しいバージョンへの自動更新を防ぎます。

### 3. 認証状態

- **認証未実装**: Flask サーバーには現在 **HTTP Basic 認証、トークンメカニズム、アクセス制御が一切ありません**。すべての API ルートとメディアエンドポイントは、LAN または FRP トンネル経由でサーバーに到達できる第三者に公開されています。
- **リスク**: `*.yunfrp.net` サブドメインを発見した未認証の第三者が、お使いのマシン上のメディアファイルを列挙しダウンロードする可能性があります。

### 4. リモートサーバー信頼

- `129.213.174.213:7000` の FRP サーバーはサードパーティの中継サーバーです。公衆インターネットとローカルサービス間のすべてのトラフィックがこのサーバーを通過します。
- FRP トンネルは HTTP モードで動作します（FRP サーバーによる TLS 終端はありません）。
- この FRP サーバー運営者がトラフィックを検査、記録、または改ざんしないことを信頼する必要があります。
