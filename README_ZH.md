## 📖 概述与核心价值

**AIpolloSync** 是一个个人媒体文件远程共享服务。它启动本地 Flask + WebRTC 媒体服务器，建立出站 FRP 隧道实现公网访问，并通过 WhatsApp 集成的 AI 代理接口暴露您的本地视频文件。

**核心价值**：随时随地通过 WhatsApp 接入 Hermes，访问您的远程媒体文件库。媒体播放列表支持 AIpollo 播放器播放。

---

## ⚙️ 使用前提

* **Hermes**: 本地已成功部署并运行 Hermes 环境。
* **安全软件加白**: 在系统安全软件（如 Windows Defender）中添加信任例外 `frpc.exe`。

---

## 🚀 具体使用步骤

1. **安装**：通过 HermesHub 下载并安装 `AIpolloSync` skill。
2. **构建本地片源库**：在本 skill 的根目录中创建 `videos` 文件夹，并将需要远程访问的 MP4 视频文件放入其中。
3. **配置 WhatsApp**：在 Hermes 中接入并完成 WhatsApp 通道配置。
4. **运行 Skill**：在 Hermes 中启动本 skill。
5. **LLM 智能交互**：在对话中自然交流即可。例如：
   - *"显示我的视频列表"*
   - *"有没有电影可以看？"*
   - *"播放关于猫的视频"*
6. **调起播放**：点击回复中生成的链接，即可播放视频。

## 🔒 安全与网络披露

### 关键：FRP 隧道会将本地服务暴露至公网

本 skill 在启动时会**自动**下载并运行 **FRP（Fast Reverse Proxy）客户端（`frpc`）**。`frpc` 二进制文件从 GitHub Releases 获取，并与远程 FRP 服务器（`129.213.174.213:7000`）建立出站隧道，从而将您的本地媒体服务（端口 8000）通过 `*.yunfrp.net` 子域名暴露至**公网**。

**这会显著扩大您的攻击面。** 任何知道或发现该公网子域名的人都可以尝试访问您机器上的媒体文件和 Flask 服务。

### 1. 自动隧道行为（无用户确认）

- **启动时自动运行**：FRP 隧道在 `scripts/media_server_flask.py` 运行时自动启动，无提示、无确认、无环境变量开关。
- **二进制下载**：首次运行时，`frpc.exe` 会从 GitHub（`fatedier/frp` releases）静默下载。需要互联网连接。
- **无需入站防火墙变更**：隧道仅为出站连接；无需在防火墙上开放入站端口。

### 2. 供应链风险：下载的二进制文件执行

- 本 skill 从 GitHub Releases 下载并执行原生二进制文件（`frpc.exe`）。若 GitHub 仓库、发布制品或网络传输（MITM）遭到入侵，可能导致在您的主机上以 Python 进程相同权限执行**任意代码**。
- **SHA256 校验锁定**：代码中硬编码了 zip 压缩包和提取的 `frpc.exe` 二进制文件（版本 `0.65.0`）的 SHA256 校验和。若任一校验和不匹配，下载将被拒绝。这可以防御传输篡改和损坏的下载，但**无法防御上游 GitHub 仓库或发布版本的入侵**。
- **版本锁定**：FRP 版本锁定在 `0.65.0`。升级需要修改代码并重新校验 SHA256。这可以防止静默升级到可能被入侵的新版本。

### 3. 认证状态

- **未实现认证**：Flask 服务器目前**没有 HTTP Basic Auth、没有 Token 机制、没有访问控制**。所有 API 路由和媒体端点对任何能访问服务器的人都是公开的——无论是通过局域网还是 FRP 隧道。
- **风险**：发现 `*.yunfrp.net` 子域名的未认证第三方可以枚举并下载您机器上的媒体文件。

### 4. 远程服务器信任

- 位于 `129.213.174.213:7000` 的 FRP 服务器是第三方中继。公网与本地服务之间的所有流量都经过此服务器。
- FRP 隧道以 HTTP 模式运行（FRP 服务器不进行 TLS 终止）。
- 您必须信任此 FRP 服务器运营商不会检查、记录或篡改您的流量。

## 🛡️ 安全实践建议

* **专用设备与隔离环境**：为了确保绝对安全，建议使用单独的闲置电脑或 NAS 作为媒体服务器，而非在主力工作设备上运行。若必须在主力机上运行，推荐使用虚拟机（VM）进行环境隔离。
* **系统安全维护**：建议定期更新并升级您的操作系统补丁与 Hermes 运行环境，防范潜在安全漏洞。
